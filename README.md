# About Arceus Labs

A simple static website introducing Arceus Labs - an open source hardware organization.

## Overview

This is the "About" page for Arceus Labs, built as a static HTML site with Tailwind CSS. It explains the mission, introduces the founder, and provides information for potential contributors.

## Tech Stack

- HTML5
- Tailwind CSS
- Vanilla JavaScript
- Hosted on Vercel

## Development

### Install Dependencies
```bash
npm install
```

### Development Mode
```bash
npm run dev
```
This watches for changes and rebuilds the CSS automatically.

### Build for Production
```bash
npm run build
```
This creates a minified CSS file for production.

## Structure

- `index.html` - Main page content
- `assets/style.css` - Tailwind input file
- `assets/output.css` - Generated CSS (don't edit directly)
- `tailwind.config.js` - Tailwind configuration
- `vercel.json` - Vercel deployment config

## Features

- Responsive design
- Retro terminal aesthetic with VT323 font
- Animated star field background
- Contact form for potential contributors
- Links to GitHub and main website
